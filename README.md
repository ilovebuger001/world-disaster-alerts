# World Disaster Alerts

* `backend/` — the real system: Rust backend + map frontend built from the Rev.2.9
  engineering specification (Phases 1–3). See [backend/README.md](backend/README.md).
* `index.html` — the earlier static design preview served by GitHub Pages
  (sample data only, not real alerts).

Information and situational awareness only — not an emergency-services or dispatch system.
The absence of an alert is never evidence that an area is safe. Always follow local authorities.
